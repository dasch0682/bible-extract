# Corpus

Placer ici `lsg1910.json` (Segond 1910, domaine public), au format :

{ "JHN": { "14": { "6": "Jésus lui dit: Je suis le chemin, la vérité, et la vie. ..." } } }

- Clés livres = codes USFM de `books.py` (JHN, 1CO, PSA...).
- Chapitres et versets = chaînes numériques.
- Source non vérifiée : chercher une base Segond 1910 en open data (eBible.org, dépôts GitHub),
  la convertir à ce format et contrôler quelques versets avant usage.
